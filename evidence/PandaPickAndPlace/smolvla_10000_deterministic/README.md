# SmolVLA PandaPickAndPlace 10000-step Deterministic Evaluation

Deterministic evaluation evidence for the SmolVLA checkpoint trained on
500 successful TQC teacher demonstrations.

## Checkpoint

`outputs/train/smolvla_panda_pickandplace_tqc_500_10000/checkpoints/010000/pretrained_model`

## Dataset

- Repo ID: `local/panda_pickandplace_tqc_teacher_500`
- Episodes: 500
- Frames: 3712
- Task: `pick and place the cube`
- Teacher: `chencliu/tqc-PandaPickAndPlace-v3`

## Training

- Training steps: 10000
- Batch size: 2
- Approximate dataset epochs: 5.39
- Chunk size: 1
- Action steps: 1
- Vision encoder frozen: yes
- Expert-only training: yes
- State projection trained: yes

## Offline comparison

- Samples: 3712
- Mean base L2 error, real 4D: 1.8888
- Mean checkpoint L2 error, real 4D: 0.5119
- Relative improvement: 72.90%

Offline action proximity does not prove rollout success, but confirms that
the trained checkpoint is substantially closer to the teacher actions
than the base SmolVLA model.

## Conclusion

The official action scale for this checkpoint is `1.0`.

The checkpoint achieved:

- 17 successful episodes out of 50
- 34% deterministic success rate
- episode seeds 0-49
- byte-reproducible policy evaluation

Action scale 1.0 produced more successes and better reward than 0.75,
although some failed episodes showed stronger divergence.

The next experiment is a 25000-step training run on the same 500-episode
dataset. The 10000-step result documented here is the baseline for that
comparison.

Previous rollouts without explicit policy RNG seeding are retained only
as historical results and are not the official deterministic baseline.
